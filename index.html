Install RavCentral

Install our official web app to your home screen or desktop for fast, one-tap access.

Samsung FixSamsung S24/S25 "Auto Blocker"
On Samsung Galaxy devices (One UI 6 & 7), Samsung's new Auto Blocker feature blocks web app APK installation by default. To allow installation, go to phone Settings > Security and privacy > Auto Blocker and turn it Off temporarily (or turn off Maximum Restrictions), then tap Install.

AlternativeUse "Add to Home screen"
In Chrome, tap the ⋮ (three dots) menu and select "Add to Home screen" (or "Create shortcut"). This bypasses APK restrictions and adds the standalone app directly to your home screen.

Residual AppUninstall from Android Settings
If previously installed, dragging the icon off the home screen may leave residual data in Android. Go to phone Settings > Apps > See all apps > RavCentral and tap Uninstall.

Reset CacheClear Site Data in Chrome
In Chrome address bar, tap the lock/tune icon > Site settings > Clear & reset data, then refresh.
